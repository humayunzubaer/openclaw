# Module 01: কাস্টমস আইন, ২০২৩ (Customs Act, 2023)
**Primary source:** bdlaws.minlaw.gov.bd → Act 1476 【V】
**কার্যকারিতা:** Customs Act, 1969 রহিত করে প্রণীত; SRO নং ১৫৩-আইন/২০২৪ (২৮-০৫-২০২৪) দ্বারা **০৬-০৬-২০২৪** থেকে কার্যকর 【V】

---

## ১. অডিট-সংশ্লিষ্ট সংজ্ঞা — ধারা ২ 【V】

| দফা | সংজ্ঞা | অডিট-তাৎপর্য |
|---|---|---|
| ২(৯) | "ওয়্যারহাউস" = ধারা ১১-এর অধীন ঘোষিত (সরকারি) বা ধারা ১২-এর অধীন লাইসেন্সপ্রাপ্ত (বেসরকারি) স্থান | বন্ড লাইসেন্স = ধারা ১২-এর private warehouse license |
| ২(১০) | "ওয়্যারহাউসিং স্টেশন" = ধারা ১০-এর অধীন ঘোষিত | |
| ২(১৯)(ঙ) | "কাস্টমস পদ্ধতি"-র একটি: কাস্টমস ওয়্যারহাউসিং | বন্ড সুবিধা = একটি customs procedure; procedure-এর শর্তভঙ্গ = আইনভঙ্গ |
| ২(২১) | "কাস্টমস মূল্য (assessable value)" = ধারা ২৭ অনুযায়ী নিরূপিত | DTA বিক্রয়/শুল্ক demand-এর ভিত্তি |
| ২(২৪) | "চোরাচালান" — লুকানো পণ্য, অঘোষিত রুট ইত্যাদি | বন্ড-পণ্য গোপনে অপসারণ চোরাচালান-উপাদান স্পর্শ করতে পারে; তবে SCN-এ সতর্কতা (নিচে [বিচারক]) |
| ২(২৯) | "ন্যায়নির্ণয়ন (adjudication)" = জরিমানাযোগ্য কাস্টমস অপরাধে যথাযথ কর্মকর্তার প্রশাসনিক কার্যক্রম | |
| ২(৪২) | "যথাযথ কর্মকর্তা (appropriate officer)" | নোটিশ/আদেশে ক্ষমতাপ্রাপ্তি উল্লেখ আবশ্যক |

**ধারা ৪ 【V】:** কর্মকর্তা-পদক্রমে (গ) কমিশনার অব কাস্টমস (বন্ড) স্বতন্ত্র পদ; (ঢ) অ্যাসিস্ট্যান্ট কমিশনার, (ণ) রাজস্ব কর্মকর্তা, (ত) **সহকারী রাজস্ব কর্মকর্তা** আইনে স্বীকৃত।
**ধারা ৩ 【V】:** অন্য আইনের উপর এ আইনের প্রাধান্য (overriding effect)।

## ২. ওয়্যারহাউস প্রতিষ্ঠা — ধারা ১০–১২ 【V】

**ধারা ১২(১):** কমিশনার (বন্ড) বা ক্ষমতাপ্রাপ্ত কমিশনার বেসরকারি ওয়্যারহাউস লাইসেন্স দিতে পারেন — উদ্দেশ্য: (ক) লাইসেন্সির আমদানিকৃত শুল্কযোগ্য পণ্য মজুদ, (খ) সরকারি ওয়্যারহাউসে স্থানাভাবের পণ্য মজুদ, **(গ) আমদানিকৃত শুল্কযোগ্য পণ্য থেকে সম্পূর্ণ/আংশিক পণ্য প্রক্রিয়াকরণ বা প্রস্তুতকরণ** — ← রপ্তানিমুখী বন্ডেড কারখানার আইনি ভিত্তি।
**১২(৩):** শুল্ক-কর পরিশোধ নিশ্চিতে **গ্যারান্টি** নির্দেশের ক্ষমতা।
**১২(৪):** লাইসেন্স স্থগিত/বাতিলের কারণ — (ক) আইন/বিধি/লাইসেন্স-শর্ত ভঙ্গ, (খ) জনস্বার্থ। **১২(৫):** জনস্বার্থে স্থগিতকালে **BIN স্থগিত**। **১২(৬):** বাতিল হলেও সরকারি পাওনা আদায় চলবে।

- **[লার্নার]** বন্ড লাইসেন্স মানে সরকার শর্তসাপেক্ষে শুল্ক স্থগিত রেখে কাঁচামাল কারখানায় ঢুকতে দিচ্ছে; শর্ত ভাঙলে লাইসেন্স ও BIN দুটোই ঝুঁকিতে।
- **[কর্মকর্তা]** অডিট শুরুতে লাইসেন্স ফাইল টানুন: অনুমোদিত পণ্য-তালিকা (annexure), অনুমোদিত মেশিনারি, ঠিকানা, মালিকানা-কাঠামো, নবায়ন-ধারাবাহিকতা। লাইসেন্স-বহির্ভূত মেশিনারি/HS আমদানি = ১২(৪)(ক) লঙ্ঘন-ভিত্তি (নজির-ক machinery finding-এর pattern)।
- **[বিচারক]** ১২(৪) প্রয়োগে proportionality দেখা হয়; ছোট প্রক্রিয়াগত ত্রুটিতে সরাসরি বাতিল টেকে না — SCN-এ প্রথমে শর্তভঙ্গ + শুল্ক-দায় প্রতিষ্ঠা করুন, বাতিল/স্থগিত সুপারিশ পৃথক প্রশাসনিক প্রস্তাবে।

## ৩. ষোড়শ অধ্যায় — ওয়্যারহাউসিং (ধারা ১০৮–১৩৩) 【V】 ★ KB-র মেরুদণ্ড

| ধারা | বিধান-সার | অডিট hook |
|---|---|---|
| ১০৮ | শর্ত-সাপেক্ষে শুল্ক-কর **পরিশোধ ব্যতীত** ওয়্যারহাউসে ন্যস্তকরণ | সুবিধার মূল; প্রতিটি শর্ত = পরীক্ষণীয় |
| ১০৯ | আমদানিকারক কমিশনার (বন্ড)-নির্ধারিত অঙ্ক/শর্তে **সাধারণ বন্ড (general bond)** দাখিল করবেন; হস্তান্তর/স্থানান্তরেও বন্ড কার্যকর; নতুন গ্রহীতা থেকে নতুন বন্ড | বন্ড দলিলের অঙ্ক বনাম বকেয়া দায় মিলান |
| ১১০ | বন্ডের অতিরিক্ত **ব্যাংক গ্যারান্টি** (শুল্কের অনধিক) নির্দেশের ক্ষমতা | |
| ১১১ | খালাসকৃত পণ্য নির্ধারিত ওয়্যারহাউসেই জমা নিশ্চিতকরণ | in-bond entry যাচাই |
| ১১৩(১) | ওয়্যারহাউসকৃত সকল পণ্য যথাযথ কর্মকর্তার নিয়ন্ত্রণে | |
| ১১৩(২) | বন্ড কমিশনারেট / কাস্টমস গোয়েন্দা / **মূল্যায়ন ও অভ্যন্তরীণ নিরীক্ষা কমিশনারেটের AC-পদমর্যাদার নিম্নে নয়** এমন কর্মকর্তা ওয়্যারহাউসে প্রবেশ ও পণ্য-রেকর্ড-হিসাব-দলিল পরীক্ষা করতে পারবেন | অডিট-প্রবেশাধিকারের সরাসরি বিধান |
| ১১৪–১১৫ | খোলা/ওজন/পরীক্ষা, সিল-মার্ক; মালিকের প্রবেশাধিকার | stock verification-এর আইনি ভিত্তি |
| ১১৬ | মালিকের অধিকার: পৃথককরণ, বাছাই, নমুনা; ধ্বংস + শুল্ক মওকুফ (কর্মকর্তার অনুমোদনে) | নমুনা-খাতে ঘাটতির বৈধতা-সীমা |
| **১১৭(১)** | লাইসেন্স-শর্ত সাপেক্ষে ওয়্যারহাউসকৃত পণ্যে **প্রস্তুতকরণ প্রক্রিয়া** | in-bond manufacturing |
| **১১৭(২)(ক)** | উৎপাদিত পণ্য **রপ্তানি** হলে সংশ্লিষ্ট অপচয়/বর্জ্যে শুল্ক নয় — **শর্ত:** বর্জ্য ধ্বংস করতে হবে, নয়তো "যেন ঐ অবস্থায় আমদানিকৃত" ধরে শুল্ক | wastage test-এর মূল ধারা |
| **১১৭(২)(খ)** | দেশীয় ভোগে খালাসকৃত অংশ + সংশ্লিষ্ট অপচয়/বর্জ্যে শুল্ক-কর; মূল্য নিরূপণ করবেন **কমিশনার (বন্ড)** | DTA-বিক্রীত waste/by-product duty demand |
| ১১৮ | দেশীয় ভোগ/রপ্তানি খালাস, অন্য ওয়্যারহাউসে অপসারণ বা আইনি প্রক্রিয়া ব্যতীত পণ্য বের করা নিষিদ্ধ | অননুমোদিত অপসারণ = লঙ্ঘনের সংজ্ঞা |
| ১১৯ | ওয়্যারহাউসিং মেয়াদ **বিধি দ্বারা** (শ্রেণিভেদে ভিন্ন হতে পারে); গণনা: ছাড়ের তারিখ থেকে | Storage Period Rules 2024 দেখুন (Module 02) |
| ১২০ | লাইসেন্স বাতিলে ১০ দিনের মধ্যে পণ্য অপসারণ/খালাস | |
| ১২১–১২৩ | একই স্টেশনে/ভিন্ন স্টেশনে ওয়্যারহাউস-স্থানান্তর (bond-to-bond transfer), গন্তব্যে পুনঃ entry | inter-bond transfer trail |
| ১২৪ | দুর্ঘটনায় ক্ষতিগ্রস্ত পণ্যের পুনর্মূল্যায়ন; হ্রাসকৃত শুল্কের **দ্বিগুণ** অঙ্কের নতুন বন্ড | |
| ১২৫ | বোর্ড-নির্ধারিত উদ্বায়ী পণ্যের **স্বাভাবিক অপচয়-ঘাটতি**তে শুল্ক নয় (কমিশনার-বন্ডের সন্তুষ্টি সাপেক্ষে) | গেজেট-তালিকাভুক্ত পণ্য ছাড়া এ ছাড় দাবি অগ্রাহ্য |
| **১২৬** | দাবিনামা-যোগ্য: (ক) ধারা ১১৮ লঙ্ঘনে অপসারিত, (খ) ১২০-এর সময়ে অপসারিত নয়, (গ) ১০৯-বন্ডকৃত অথচ খালাস/অপসারণ/১১৬-১১৭ ব্যবস্থিত নয় বা ১২৯-বহির্ভূতভাবে ক্ষতিগ্রস্ত **বা যথাযথ কর্মকর্তার সন্তুষ্টিমতে হিসাব-অপ্রদত্ত**, (ঘ) ১১৬-নমুনা — ভাড়া-জরিমানা-সুদসহ সমুদয় শুল্ক অবিলম্বে | **ঘাটতি/unaccounted stock-এর duty demand-এর প্রধান ধারা** |
| **১২৭** | ১২৬-দাবি অনাদায়ে: বন্ডের উপর ব্যবস্থা **অথবা** ওয়্যারহাউসের পণ্য, **কারখানা-যন্ত্রপাতি-মেশিনারি** বা অন্য সম্পত্তি আটক → ১৫ দিনের নোটিশ → বিক্রয় → বন্ড-দায় সমন্বয়; উদ্বৃত্ত ধারা ২৩৭ মতে | recovery escalation path |
| ১২৮ | ওয়্যারহাউস রক্ষকের **stock-keeping-সহ সকল রেকর্ড** সংরক্ষণ (বোর্ড-নির্ধারিত পদ্ধতি) | বন্ড রেজিস্টার/রেকর্ডের আইনি বাধ্যবাধকতা |
| ১২৯ | অনিবার্য দুর্ঘটনায় ধ্বংসে শুল্ক মওকুফের বিবেচনা-ক্ষমতা; বেসরকারি ওয়্যারহাউসে ঘটনার **৩ কর্মদিবসে লিখিত নোটিশ** বাধ্যতামূলক | নোটিশ-বিহীন "আগুন/ক্ষতি" দাবি [বিচারক]-দৃষ্টিতে দুর্বল |
| ১৩০ | রক্ষক/লাইসেন্সধারীর দায় — গ্রহণ, সরবরাহ, নিরাপদ হেফাজত (১২৫-ছাড় বাদে) | |

- **[লার্নার]** ওয়্যারহাউসের ভেতরে যা ঢুকল তার প্রতিটি কেজির হিসাব দিতে হবে — রপ্তানি, বৈধ খালাস, অনুমোদিত ধ্বংস বা স্বাভাবিক অপচয়; বাকি সব = শুল্কসহ দাবিযোগ্য।
- **[কর্মকর্তা]** ঘাটতির শ্রেণিবিন্যাস করুন: (i) coefficient-সঙ্গত ভোগ, (ii) অনুমোদিত wastage (রপ্তানি-সংশ্লিষ্ট, ধ্বংস-প্রমাণসহ), (iii) ১২৫-তালিকাভুক্ত উদ্বায়ী ঘাটতি, (iv) **অবশিষ্ট = ধারা ১২৬(গ) "হিসাব-অপ্রদত্ত"** → duty demand। DTA-বিক্রীত by-product (যেমন negative plate) → ১১৭(২)(খ) + ex-bond পদ্ধতি লঙ্ঘন হলে ১১৮/১২৬(ক)।
- **[বিচারক]** ১২৬-দাবি টেকে যখন: খোলা-বন্ধ stock গাণিতিকভাবে reconstruct করা যায়, coefficient/UP উদ্ধৃত হয়, এবং লাইসেন্সিকে হিসাব দেওয়ার সুযোগ দেওয়া হয়েছিল (শুনানির নথি)। শুধু "রেজিস্টারে গরমিল" যথেষ্ট নয় — পরিমাণগত reconciliation টেবিল সংযুক্ত করুন।

## ৪. মূল্য, হার-নির্ধারণ তারিখ, সুদ 【V】

- **ধারা ২৭:** assessable value; **২৭(৪):** বিনিময় হার = পণ্য-ঘোষণা নিবন্ধনের **পূর্ববর্তী মাসের ৩য় সপ্তাহের শেষ কার্যদিবসের পূর্বের ৩০ দিনের গড়** (বোর্ড-নির্ধারিত)।
- **ধারা ৩০(খ):** ওয়্যারহাউস থেকে দেশীয় ভোগে ছাড়ে (ধারা ১৩৪(ক)(অ)) শুল্কহার-মূল্য-বিনিময়হার নির্ধারিত হয় **ex-bond পণ্য-ঘোষণা (ধারা ৮৩) নিবন্ধনের তারিখে** — DTA duty গণনায় in-bond B/E-র তারিখ নয়, ex-bond B/E-র তারিখের হার প্রযোজ্য। ★
- **ধারা ৩২:** পরিশোধ ১০ দিনে; বিলম্বে বার্ষিক ১০% সরল সুদ; ছাড়-পরবর্তী বকেয়ায় সংশোধনী অনুযায়ী **মাসিক ১%** (নিষ্পন্নাধীন সময়সহ অনধিক ২৪ মাস; বোর্ড গুরুতর ক্ষতিতে সুদ-বিরত থাকতে পারে) 【V — bdlaws সংশোধনী পাঠ】। SCN-এ কোন হার প্রযোজ্য তা ঘটনার তারিখ-ভিত্তিক নির্বাচন করুন।
- **ধারা ৩৩:** অসত্য ঘোষণা/দলিল/যোগসাজশে শুল্ক কম-আরোপ/ভুল-ফেরত → কারণদর্শানোসহ দাবিনামা; **৩৩(৪): এ নোটিশে কোনো তামাদি নেই**। ★ প্রতারণা-উপাদান প্রমাণযোগ্য হলে limitation-বাধা কাটে।
- **ধারা ৩৪:** ফেরত-দাবি ৩ বছরে; provisional-এ ধারা ৯৩ সমন্বয়-তারিখ থেকে গণনা।

## ৫. পণ্য ঘোষণা, শুল্কায়ন, PCA 【V】

- **ধারা ৮১–৮৪:** goods declaration; **৮৪(১):** পণ্য পৌঁছা/অবতরণের **৫ কর্মদিবসে** দাখিল; **৮৪(২):** ৩০ দিন-প্রত্যাশায় অগ্রিম দাখিল।
- **ধারা ৮৬(৪):** কাস্টমস এলাকা থেকে অপসারণের পর **পরিমাণ, মূল্য ও বর্ণনা সংশোধন নিষিদ্ধ** (ধারা ১১২-ব্যতিক্রম বাদে) — পরবর্তী "সংশোধিত ঘোষণা"-নির্ভর ব্যাখ্যা প্রত্যাখ্যানের ভিত্তি।
- **ধারা ৯০–৯১:** শুল্কায়ন; পুনঃশুল্কায়নে **লিখিত কারণ + মতামত + শুনানি** বাধ্যতামূলক, দাবিনামার ৩০ কর্মদিবসে পরিশোধ।
- **ধারা ৯৩:** provisional assessment; চূড়ান্তকরণ **১২০ কর্মদিবসে** (মামলাধীন হলে নিষ্পত্তি-তারিখ থেকে ১২০)।
- **ধারা ৯৪:** বন্দর/স্থল/ICD-তে ৩০ দিন, বিমানবন্দরে ২১ দিনে ছাড় না হলে নির্দিষ্ট কারণে সরকারের নিকট হস্তান্তরিত-গণ্য; শুল্ক না দিয়ে দেশীয়-ভোগ-পণ্য অপসারণ নিষিদ্ধ।
- **ধারা ৯৯:** Post Clearance Audit — রেকর্ড-স্থানে প্রবেশ, হিসাবপুস্তক-রেকর্ড-দলিল পরীক্ষা, উদ্ধৃতি/অনুলিপি গ্রহণ; বেসরকারি **আবাসস্থলে** সম্মতি/পরোয়ানা ছাড়া প্রবেশ নিষেধ (৯৯(৪))।
- **ধারা ১০০:** বোর্ড বিশেষ আদেশে **পেশাদার নিরীক্ষক/নিরীক্ষা ফার্ম** নিয়োগ করতে পারে; ধারা ৯৯-এর প্রয়োজনে তাঁরা কাস্টমস কর্মকর্তা-গণ্য। ★ CA-audit module-এর সরাসরি সংযোগবিন্দু (Module 04)।

## ৬. দণ্ড, তামাদি, আপিল

- **ধারা ১৭১(১):** অপরাধ-জরিমানার **টেবিল** (ক্রমিক-ভিত্তিক); যেমন ক্রমিক ১১ — কার্গো ঘোষণা-গরমিল 【V টেবিলের অস্তিত্ব ও ক্রমিক-১১ রেফারেন্স; **প্রতিটি ক্রমিকের পূর্ণপাঠ 【P】— SCN-এ উদ্ধৃতির আগে টেবিল থেকে হুবহু যাচাই বাধ্যতামূলক**】।
- **ধারা ২০৩:** জরিমানা/বাজেয়াপ্তির পূর্বে নোটিশ; **ধারা ২০৪(১):** প্রতারণা-ব্যতীত ঘটনার **৩ বছরের** মধ্যে ২০৩-নোটিশ না হলে জরিমানা/বাজেয়াপ্তি আদেশ নয় 【V】; **২০৪(৩)-এর সূচনা-বিন্দু:** (ক) provisional হলে চূড়ান্ত-সমন্বয়ের তারিখ, (খ) ভুল-ফেরতে ফেরতের তারিখ, (গ) অন্যত্র পণ্য ছাড়ের তারিখ 【V】।
- **আপিল-কাঠামো:** ন্যায়নির্ণয়ন → কমিশনার (আপিল) → আপিল ট্রাইব্যুনাল (ধারা ২২৫-গঠিত) → উচ্চ আদালত 【E — ধাপ-ধারাসমূহ (২১৯–২৩০ পরিসর) gazette-এ যাচাই করুন】।
- **[বিচারক]** তামাদি-কৌশল: সাধারণ ঘাটতি/লঙ্ঘনে ৩-বছর ঘড়ি ধরুন (২০৪); অসত্য ঘোষণা-প্রমাণে ধারা ৩৩(৪)-পথে তামাদি-মুক্ত দাবি — তবে "অসত্য" প্রমাণের ভার আরোপকারীর; দলিল-বৈসাদৃশ্যের exhibit ছাড়া এ পথ ঝুঁকিপূর্ণ।

## ৭. আনুষঙ্গিক 【V】

- **ধারা ২৫:** অব্যাহতি — (১) সরকার+বোর্ড প্রজ্ঞাপনে (এক অর্থবছরে একাধিকবার হার-বৃদ্ধি নিষেধ), (২) আন্তর্জাতিক চুক্তিতে, (৩) বিশেষ আদেশে কারণ-উল্লেখে।
- **ধারা ৩৬–৪০ (প্রত্যর্পণ):** পরিশোধিত শুল্কের অনধিক ৭/৮; শনাক্তযোগ্যতা; আমদানির ৩ বছরের সীমা; ৳২,০০০-এর নিচে দাবি নয়; রপ্তানি-তারিখের ৬ মাসে দাবি।
- **ধারা ১০৩–১০৭:** Inward/Outward Processing — ৬ মাসে (বোর্ড-বর্ধনযোগ্য) সমাপ্তি; inward-এ ব্যাংক গ্যারান্টি; অ-রপ্তানিকৃত উদ্ভূত পণ্য/বর্জ্যে শুল্ক (১০৬(৩))।
- **ধারা ৪১–৪৬:** গ্যারান্টির ধরন — নগদ, ব্যাংক গ্যারান্টি/surety, বন্ড; ঝুঁকিভিত্তিক পর্যায়-নির্ধারণ (ধারা ৪৪); অবমুক্তি (ধারা ৪৬)।
