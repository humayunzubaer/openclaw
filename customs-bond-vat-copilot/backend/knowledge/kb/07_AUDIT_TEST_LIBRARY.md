# Module 07: Audit Test Library (Calculation Engine)
প্রতিটি test-এর গঠন: **উদ্দেশ্য → Input → সূত্র → Threshold → আইন-সূত্র → Finding-টেমপ্লেট (identify→quantify→cite→consequence)**। সব হিসাব formula-driven; hardcoded total নিষিদ্ধ। বড় অঙ্ক অঙ্কে+কথায়; লাখ/কোটি format।

---

## T-01: Bond Register Reconciliation (মূল ভারসাম্য-সমীকরণ)
**সূত্র (RM-ভিত্তিক, kg):** `Closing = Opening + Σ(B/E in-bond প্রাপ্তি) − Σ(ভোগ) − Σ(অনুমোদিত ধ্বংস/নমুনা/স্বাভাবিক-অপচয়)`; `ভোগ = Σ(রপ্তানি/Ex-Bond পরিমাণ × অনুমোদিত coefficient)`
**Threshold:** |Physical/Register − Computed Closing| > ০.৫% → ব্যাখ্যা-তলব; ব্যাখ্যা-অগ্রাহ্যে demand।
**আইন:** কাস্টমস আইন ধারা ১২৬(গ) "হিসাব-অপ্রদত্ত" 【V】 + ১২৮ (রেকর্ড-দায়) 【V】।
**Consequence:** ঘাটতি-kg × ex-bond-তারিখের assessable value/kg × পূর্ণ শুল্ককর-হার + সুদ (ধারা ৩২)।

## T-02: VAT Triangle Test (দাখিলপত্র-ত্রিভুজ)
**তিন শীর্ষ:** Mushak 9.1 ↔ Mushak 6.1/6.2 রেজিস্টার ↔ Ledger+Bank/FS।
**পরীক্ষা:** (ক) মাসভিত্তিক শূন্যহার-রপ্তানি = Σ B/Ex-FOB×rate; (খ) রেয়াত-দাবি ↔ ৬.১-চালান-ভিত্তি (ধারা ৪৬-শর্ত); (গ) **Frozen-note detector:** কোনো note-এ ≥৩ মাস অভিন্ন অঙ্ক (variance=0) → স্বয়ংক্রিয় লাল পতাকা (RGL Note-52, ৳২,৫৪,৮৪১×১২ মাস-ধাঁচ); (ঘ) VDS-জোড়া-মিল (Module 04)।
**আইন:** মূসক আইন ধারা ৬৪, ৮৫, ৮৬ 【V-অবস্থান】।
**Consequence:** ভুল/অসত্য দাখিলপত্র → ধারা ৮৫-জরিমানা (প্রয়োগ-চর্চায় সর্বোচ্চ-সীমা উদ্ধৃতিসহ) + কর-প্রভাব থাকলে পৃথক দাবি। **Temporal:** ২০২৬-০৭ থেকে ত্রৈমাসিক-চক্রে cadence বদল (Module 03)।

## T-03: FIFO Consumption Tracking
**পদ্ধতি:** B/E-lot-ভিত্তিক queue; প্রতিটি ভোগ-এন্ট্রি প্রাচীনতম-lot থেকে কাটা; lot-বয়স = ভোগ-তারিখ − in-bond-তারিখ।
**Threshold 【V — SRO ২১১-আইন/২০২৪-গেজেট-পাঠ; Module 09-গ】:** সরাসরি/প্রচ্ছন্ন রপ্তানিমুখী **২৪ মাস** (জাহাজ-নির্মাণ ৪৮; ডিউটি ফ্রি/পেইড/ডিপ্লো/কমিশারিয়েট ১২; দেশীয়-ভোগ ৬); গণনা-সূচনা: আমদানিতে ছাড়ের তারিখ, স্থানীয়ে মূসক-চালান-তারিখ; কমিশনার (বন্ড) +৬ মাস পর্যন্ত, তদূর্ধ্বে NBR case-to-case (শর্ত: মান-অক্ষুণ্ন, রপ্তানি-সক্ষমতা, নিরীক্ষা-নবায়ন হালনাগাদ, দণ্ডাদেশ-মুক্ত)। lot-বয়স > প্রযোজ্য মেয়াদ (+অনুমোদিত বর্ধন) → মেয়াদোত্তীর্ণ-মজুদ finding; ঋণাত্মক-lot (ভোগ>প্রাপ্তি) → রেজিস্টার-অসত্যতা।
**আইন:** ধারা ১১৯ 【V】 + SRO ২১১-আইন/২০২৪/৬৩ বিধি ৩-৫ 【V】।

## T-04A: আমদানি প্রাপ্যতা-সীমা (Entitlement Ceiling) 【V — SRO ২১৪/২০২৪】
**সূত্রসমূহ:** `বার্ষিক উৎপাদন ক্ষমতা = ৩০০ × শিফট × ৮ × মেশিন সংখ্যা × ঘণ্টা-প্রতি ক্ষমতা` (বিধি ৩(৪); ৩ শিফট-ঘোষণায় ২৪ ঘণ্টা কমিশনার-বিবেচনায়);
`নূতন লাইসেন্স প্রাপ্যতা = ক্ষমতার ৩০%` (বিধি ৪); `নবায়নে প্রাপ্যতা = পূর্ববর্তী বৎসরের রপ্তানিতে ব্যবহৃত কাঁচামাল + ২০% (মজুদসহ)`, Compliant হলে ক্ষমতার ৬০% পর্যন্ত (বিধি ৫(৩));
**হার্ড সিলিং:** `প্রাপ্যতা + প্রারম্ভিক মজুদ ≤ ক্ষমতার ৮০%` (বিধি ১১(১)); `এককালীন মজুদ ≤ min(প্রাপ্যতা ÷ ৩, ধারণক্ষমতা)` (বিধি ১৫ + SRO ২০৯-বিধি ৭)।
**Compliance-গেট (বিধি ৫ ব্যাখ্যা):** বিচারাদেশ-মুক্ত (বা রাজস্ব-জরিমানা পরিশোধিত) **এবং** পূর্ববর্তী ≥১ অর্থবৎসরে মূসক-৯.১ দাখিলে ব্যর্থতা নেই — ব্যর্থ হলে ৬০%-সুবিধা প্রযোজ্য নয়।
**বৃদ্ধি-নিষেধ (বিধি ১১(৩)):** ধারা ২৩৮-নোটিশ বিদ্যমান / জালিয়াতি প্রমাণিত / লাইসেন্স স্থগিত / সরকারের পক্ষে চূড়ান্ত রায়ে অর্থ অপরিশোধিত।
**Finding-ধরন:** সীমা-অতিক্রান্ত আমদানি → বিধি ১২-মতে BG-বিহীন খালাস হলে অনিয়ম; মেশিন হ্রাসে প্রাপ্যতা পুনঃনির্ধারণ না হওয়া (বিধি ১০(২)); অননুমোদিত (লাইসেন্সে অসংযোজিত) মেশিন ক্ষমতা-গণনায় অন্তর্ভুক্ত (বিধি ২(ক)); ৬০%/২০%-অতিক্রমে কমিশনার-অনুমোদন অনুপস্থিত (বিধি ১৪)।

## T-04: Coefficient/UP-UD Utilization
**সূত্র:** `প্রাপ্য-input = Σ(রপ্তানি-qty × coefficient)`; `Over-drawal = প্রকৃত-খালাস − প্রাপ্য`; মেয়াদ-চেক: খালাস-তারিখ ∈ UP/UD/DEDO-বৈধতা-সীমা।
**Findings:** মেয়াদোত্তীর্ণ সহগে খালাস (DEDO পূর্ব-দৃষ্টান্ত); over-drawal-kg-এর duty-exposure।
**আইন:** UP/UD-শর্ত + ধারা ১২(৪)(ক) 【V】 + ১২৬ 【V】।

## T-05: Wastage Test
**সূত্র:** `প্রকৃত-wastage% = (Input − Output-equivalent-input)/Input ×100`; `অতিরিক্ত = max(0, প্রকৃত% − অনুমোদিত%) × Input-kg`।
**শাখা-যুক্তি (ধারা ১১৭(২) 【V】):** রপ্তানি-সংশ্লিষ্ট wastage → ধ্বংস-প্রমাণ আছে? হ্যাঁ=শুল্কমুক্ত; না → "যেন ঐ-অবস্থায় আমদানিকৃত" শুল্ক। DTA-বিক্রীত wastage → ১১৭(২)(খ) মূল্য-নিরূপণ কমিশনার (বন্ড)।
**RGL-প্রয়োগ-নজির:** ২৮৭ shipping bill × ২৭ RM-কলামে ৩.৩৪% অডিটর-হার → মোট দাবি ≈ ৳৩,৭৫,০০,০০০/- (তিন কোটি পঁচাত্তর লক্ষ টাকা) 【V-by-practice】।

## T-06: Value Addition Test
**আদর্শ-সূত্র:** `VA% = (রপ্তানি-FOB − আমদানিকৃত-input-মূল্য) / আমদানিকৃত-input-মূল্য × 100`  (ভিত্তি = input-মূল্য; নিরীক্ষক-নির্ধারিত)
**Threshold 【V】:** ইউপিতে মূল্য সংযোজনের হার উল্লেখ বাধ্যতামূলক এবং **১৫%-এর কম হইবে না — SRO ২১২-আইন/২০২৪/৬৪ বিধি ১০(৮)** (গেজেট-পাঠ; Module 09-খ.১); গণনার বিধিবদ্ধ স্থান: UP-ফরম্যাট তফসিল-২ ক্রমিক ১৪(ঘ)। খাতভিত্তিক ভিন্ন-হার-আদেশ থাকলে তা প্রাধান্য পাবে 【E-খাতচেক】।
**ভিত্তি-detector:** সঠিক ভিত্তি = input-মূল্য (নিরীক্ষক-নির্ধারিত; Gold Shine ২৩.৪৫%)। base-এ input-এর বদলে FOB বসালে VA কম দেখায় — engine উভয় সূত্রে গণনা করিয়া বৈসাদৃশ্য flag করে।
**নজির:** Fujian — VA ১১.৪০% < ১৫% ন্যূনতম, ১৪২-BBLC পরিসরে মোট ঝুঁকি > ৳১,৫৭,০০,০০০/- (এক কোটি সাতান্ন লক্ষ টাকা) 【V-by-practice】।

## T-07: BTB LC Three-Way Match
**সেট-তুলনা:** `L_bank` (AD-বিবরণী) ∩ `L_customs` (B/E-LC-রেফ) ∩ `L_register` (বন্ড-রেজিস্টার)। 
**Findings:** `L_bank ∖ L_register` = রেজিস্টার-বহির্ভূত LC (RGL: ১০৭টি) → উৎস-অর্থায়নে আমদানি কোথায় গেল?; `L_register ∖ L_customs` = ভুতুড়ে এন্ট্রি। Entitlement-চেক: Σ BTB ≤ master-LC-সীমা 【E-শতাংশ】।

## T-08: Export Proceeds Ageing
**সূত্র:** `Due = B/Ex(বা EXP)-তারিখ + ১২০ দিন`; `Overdue-days = Realization/PRC-তারিখ − Due` (ঋণাত্মক হলে compliant)।
**আইন:** FERA 1947 (প্রত্যাবাসন-দায় 【E-ধারা】) + GFET; **প্রতিবেদনে supplementary observation-শ্রেণি** (Module 06-নীতি)।
**Output:** overdue-চালান-তালিকা (B/Ex, মূল্য, দিন), মোট অপ্রত্যাবাসিত অঙ্ক।

## T-09: DTA/Ex-Bond Duty Assessment
**সূত্র (প্রতি-চালান):** `AV = qty × unit-value` (ধারা ২৭ 【V】; হার-তারিখ = ex-bond ঘোষণা-নিবন্ধন, ধারা ৩০(খ) 【V】) → স্তর-গণনা: `CD = AV×cd%`; `RD = AV×rd%`; `SD = (AV+CD+RD)×sd%`; `VAT = (AV+CD+RD+SD)×15%`; `AIT = AV×ait%`; `AT = (AV+CD+RD+SD)×at%` 【গণনা-ক্রম প্রচলিত ASYCUDA-পদ্ধতি 【E】; প্রতিটি হার HS-ভিত্তিক Operative-Tariff থেকে — কখনো অনুমান নয়】।
**নজির:** RGL negative plate ৩৫,১০,০০০ পিস, HS 8507.90.90 → দাবি ≈ ৳৫,৪৭,০০,০০০/- (পাঁচ কোটি সাতচল্লিশ লক্ষ টাকা) 【V-by-practice】।

## T-10: Machinery/Capital Import Compliance
**পরীক্ষা:** মেশিনারি-B/E-তালিকা ↔ লাইসেন্স-annexure/অনুমোদনপত্র; অননুমোদিত-স্থাপনা → ধারা ১২(৪)(ক)-লঙ্ঘন + অব্যাহতি-শর্তভঙ্গে শুল্ক-এক্সপোজার (অব্যাহতি-SRO-শর্ত উদ্ধৃত করুন 【P-SRO-নম্বর প্রতি-কেসে】)।
**নজির:** RGL — ৮টি B/E, AV ≈ ৳২,১২,০০,০০০/- (দুই কোটি বারো লক্ষ টাকা) 【V-by-practice】।

## T-11: Financial Solvency & Ownership
**Input:** Audited FS (equity, ratios), RJSC Form XII, লাইসেন্স-নথি।
**নিয়ম:** Equity < 0 বা ধারাবাহিক ক্ষয় → বিধি ১৬-উদ্বেগ 【E】; লাইসেন্স-বহির্ভূত মালিকানা-বদল → বিধি ২০ 【E】; উভয়ে প্রশাসনিক-সুপারিশ-শ্রেণি (শুল্ক-দাবি নয়)।

## T-12: উৎসে মূসক Four-Layer Reconciliation
Module 04-খ.৩-এর পূর্ণ পদ্ধতি: `VDS-কর্তনযোগ্য (ledger-ছাঁকনি × হার-ছক)` = `ledger-দায়` = `ট্রেজারি-চালান` = `9.1-বৃদ্ধিকারী-সমন্বয়` = `৬.৬-রেজিস্টার`; যেকোনো স্তর-ফাটল = finding। হার-ছক অর্থবছর-সংস্করণ-লকড 【P-প্রতি-বছর】।

## T-13: Zero-Rated Documentation Review
**চেকলিস্ট (প্রতি-রপ্তানি):** B/Ex + EXP + LC/Contract + Invoice/Packing + BL/AWB + PRC — যেকোনোটির অনুপস্থিতি → শূন্যহার-দাবি-ঝুঁকি-তালিকা; deemed-export হলে local-BTB-LC + প্রাপ্তি-প্রমাণ।
