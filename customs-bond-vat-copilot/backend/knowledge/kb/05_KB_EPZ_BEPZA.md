## ২. EPZ-প্রতিষ্ঠানের পণ্য-চক্র (audit trail-দৃষ্টিতে)

1. **আমদানি:** BEPZA **Import Permit (IP)** + কাস্টমস B/E (জোন-স্টেশন) — শুল্ক-করমুক্ত প্রবেশ; IP-তালিকা বনাম B/E-তালিকা reconciliation প্রথম test।
2. **মজুদ-ভোগ:** জোনের বন্ড-রেজিস্টার-সমতুল্য রেকর্ড; coefficient-শৃঙ্খলা একই দর্শনে।
3. **রপ্তানি:** BEPZA **Export Permit (EP)** + B/Ex + EXP; জোন-থেকে-জোন / জোন-থেকে-বন্ড হস্তান্তরে আন্তঃ-transfer দলিল।
4. **DTA (Domestic Tariff Area) বিক্রয়:** DTA-ক্রেতার নামে **আমদানি-গণ্য B/E**; প্রযোজ্য CD+RD+SD+VAT+AIT+AT পূর্ণহারে; অনুমতি-স্তর (BEPZA + কাস্টমস) 【E-পদ্ধতি, প্রতিষ্ঠিত চর্চা】। DTA-অনুমোদনযোগ্য সর্বোচ্চ-শতাংশ/শর্ত নীতি-দলিলভেদে 【P — প্রযোজ্য বছরের IPO/BEPZA-পরিপত্র থেকে নিন】।
5. **Sub-contracting:** জোন↔DTA উভয়মুখে পূর্বানুমোদন (BEPZA এবং প্রযোজ্য ক্ষেত্রে বন্ড কমিশনারেট); অনুমোদনপত্র-মেয়াদ-পরিমাণ ট্র্যাক 【E】।
6. **Waste/by-product নিষ্পত্তি:** ধ্বংস-কমিটি/অনুমোদিত DTA-বিক্রয়; অননুমোদিত DTA-প্রবাহ = নজির-ক negative-plate-ধাঁচের finding — শুল্কায়ন-ভিত্তি: ex-bond/DTA B/E-তারিখের হার (Module 01 ধারা ৩০(খ)-সাদৃশ্য) + HS-ভিত্তিক পূর্ণ শুল্ককর।

- **[লার্নার]** EPZ মানে "দেশের ভেতরে শুল্ক-সীমার বাইরে" — ভেতর থেকে দেশের বাজারে কিছু গেলেই সেটা "আমদানি"।
- **[কর্মকর্তা]** EPZ-অডিটে তিন-উৎস মিলান: **BEPZA-ডেটা (IP/EP) ↔ ASYCUDA/কাস্টমস (B/E, B/Ex) ↔ প্রতিষ্ঠান-রেজিস্টার**; NBR MIS-Excel-এ header সাধারণত ৭–১২ সারিতে — probing বাধ্যতামূলক (প্রকল্প-নিয়ম)।
- **[বিচারক]** DTA-demand-এ HS-শ্রেণিবিন্যাস-ই প্রধান আক্রমণ-ক্ষেত্র; classification-যুক্তি (GRI, tariff-heading পাঠ) finding-এই লিখে দিন, নইলে আপিলে হারানো সহজ।

## ৩. EPZ বনাম non-EPZ পার্থক্য-সারণি (engine-switch)

| মাত্রা | EPZ-প্রতিষ্ঠান | Non-EPZ বন্ড |
|---|---|---|
| লাইসেন্স-উৎস | BEPZA-অনুমোদন + কাস্টমস-নিয়ন্ত্রণ; EPZ Rules 1984 | কমিশনার (বন্ড), ধারা ১২ + SRO ২০৯-আইন/২০২৪ |
| আমদানি-অনুমতি-দলিল | IP | UP/UD + লাইসেন্স-annexure |
| প্রযোজ্য ওয়্যারহাউসিং-মেয়াদ | জোন-নিয়ম 【P】 | Storage Period Rules 2024 【P-সংখ্যা】 |
| DTA-পথ | আমদানি-গণ্য B/E, অনুমতি-স্তরসহ | ex-bond B/E (ধারা ১৩৪) |
| VAT-অবস্থান | সীমিত; DTA-লেনদেনে জাগ্রত | পূর্ণ VAT-চক্র |
| FX-নিয়ম | অভিন্ন মেরুদণ্ড (Module 06) — EPZ-বিশেষ হিসাব-সুবিধা GFET-অধ্যায়ভিত্তিক 【E】 | GFET-সাধারণ |
