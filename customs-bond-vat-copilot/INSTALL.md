# ইনস্টল ও চালানোর গাইড

**Customs Bond & VAT Audit Copilot** — আপনার কম্পিউটারে (Windows / Mac / Linux), সম্পূর্ণ অফলাইন।

---

## ধাপ ১ — Node.js ইনস্টল করুন (একবারই)

অ্যাপটি চালাতে Node.js লাগে (শুধু একবার ইনস্টল করলেই হয়)।

1. যান: **https://nodejs.org**
2. **LTS** সংস্করণটি ডাউনলোড করে ইনস্টল করুন (Next → Next → Finish)
3. ইন্টারনেট শুধু এই ইনস্টলেই লাগে; এরপর অ্যাপ অফলাইনে চলবে।

> Node.js 22 বা তার নতুন সংস্করণ দরকার।

---

## ধাপ ২ — অ্যাপ চালু করুন

zip ফাইলটি একটি ফোল্ডারে **Extract/Unzip** করুন, তারপর:

| আপনার কম্পিউটার | যা করবেন |
|------------------|-----------|
| 🪟 **Windows** | `start.bat` ফাইলে **ডাবল-ক্লিক** করুন |
| 🍎 **Mac** | `start.command` ফাইলে **ডাবল-ক্লিক** করুন |
| 🐧 **Linux** | টার্মিনালে `./start.sh` চালান |

একটি কালো উইন্ডো খুলবে ও কিছুক্ষণ পর ব্রাউজারে অ্যাপটি খুলে যাবে:
**http://localhost:4700**

> অ্যাপ ব্যবহারের সময় কালো উইন্ডোটি খোলা রাখুন। বন্ধ করলে অ্যাপও বন্ধ হবে।

### Mac-এ প্রথমবার "cannot be opened" দেখালে

macOS নিরাপত্তার কারণে আটকাতে পারে। একবার করুন: `start.command`-এ **ডান-ক্লিক → Open → Open**। এরপর থেকে ডাবল-ক্লিকেই চলবে।

---

## ধাপ ৩ (ঐচ্ছিক) — OCR চালু করা

স্ক্যান করা নথি/ছবি থেকে টেক্সট বের করতে চাইলে, একবার নিচের কাজটি করুন —

ফোল্ডারে টার্মিনাল/Command Prompt খুলে চালান:
```
npm install tesseract.js
```
তারপর অ্যাপ বন্ধ করে আবার চালু করুন। (প্রথমবার বাংলা+ইংরেজি ভাষা-ডেটা একবার নামে।)

---

## ধাপ ৪ (ঐচ্ছিক) — AI বিশ্লেষণ

অ্যাপের **⚙️ সেটিংস**-এ গিয়ে বেছে নিন:

- **শুধু নিয়ম-ভিত্তিক** — কিছু লাগে না, ১০০% অফলাইন (ডিফল্ট)
- **Ollama** — লোকাল AI মডেল (আলাদাভাবে https://ollama.com থেকে ইনস্টল)। ডেটা কম্পিউটার ছাড়ে না।
- **Claude API** — সবচেয়ে নির্ভুল; API key দিতে হবে। এতে OCR টেক্সট ইন্টারনেটে যায়।

## 📱 মোবাইল/ট্যাবে চালানো

অ্যাপটা কম্পিউটারে চলে; ফোন **একই Wi-Fi** থেকে ব্রাউজারে সংযোগ করে ব্যবহার করে। ইন্টারনেট লাগে না।

1. কম্পিউটারে অ্যাপ চালু করুন (start ফাইল দিয়ে)। কালো উইন্ডোতে এমন লেখা আসবে —
   ```
   📱 মোবাইল/ট্যাবে (একই Wi-Fi):
       http://192.168.0.105:4700
   ```
2. ফোন ও কম্পিউটার **একই Wi-Fi**-তে আছে নিশ্চিত করুন।
3. ফোনের ব্রাউজারে ঐ ঠিকানাটা (যেমন `http://192.168.0.105:4700`) টাইপ করুন।
4. অ্যাপ খুলে যাবে। **হোম-স্ক্রিনে যোগ করতে:**
   - **iPhone (Safari):** Share → *Add to Home Screen*
   - **Android (Chrome):** ⋮ মেনু → *Add to Home screen / Install app*
   এরপর সত্যিকার অ্যাপের মতো আইকন থেকে খুলবে।

> **মনে রাখবেন:** ব্যবহারের সময় কম্পিউটারে অ্যাপ চালু থাকতে হবে ও দুটো ডিভাইস একই Wi-Fi-তে থাকতে হবে। কম্পিউটার বন্ধ থাকলে ফোনে চলবে না (এটা একটা লোকাল server)।
>
> সংযোগ না হলে: কম্পিউটারের firewall পোর্ট 4700 ব্লক করছে কিনা দেখুন; একই Wi-Fi (গেস্ট নেটওয়ার্ক নয়) নিশ্চিত করুন।

## আপনার ডেটা কোথায় থাকে?

সব অডিট আপনার কম্পিউটারেই থাকে — `audits/` ফোল্ডারে, প্রতিটি অডিট একটি আলাদা ফোল্ডার। ব্যাকআপ নিতে চাইলে শুধু `audits/` ফোল্ডারটি কপি করুন। কোনো ডেটা ইন্টারনেটে যায় না (Claude API বেছে নিলে শুধু OCR টেক্সট যায়)।

## সমস্যা হলে?

- **ব্রাউজার নিজে খোলেনি?** — ম্যানুয়ালি খুলুন: `http://localhost:4700`
- **"Node.js পাওয়া যায়নি"** — ধাপ ১ আবার করুন, কম্পিউটার রিস্টার্ট দিন।
- **পোর্ট 4700 ব্যস্ত?** — অন্য পোর্টে চালাতে টার্মিনালে: `PORT=4800 node src/server.js`
