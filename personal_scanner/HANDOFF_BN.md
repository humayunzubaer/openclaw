# Personal Scanner: হস্তান্তর নোট (Base44-এর জন্য)

## এক নজরে

Personal Scanner-এর মূল অংশ, অর্থাৎ বাংলা ও ইংরেজি লেখা পড়ার **OCR ইঞ্জিন**, তৈরি ও পরীক্ষিত।
এর সাথে আছে Import Permit-এর ঘর ধরে পড়া ও নিজে নিজে হিসাব মিলিয়ে দেখার ব্যবস্থা। ইঞ্জিনটাকে এখন
একটা **সার্ভার** হিসেবে চালানো যায়, আপনার Hostinger VPS-এ Docker দিয়ে।

যা নেই, তা হলো ব্যবহারকারীর **অ্যাপ (স্ক্রিন, আপলোড, ইতিহাস, এক্সপোর্ট)**। সেটাই Base44 বানাবে।

```
আপনার ফোন/কম্পিউটার ──► Base44 অ্যাপ ──► আপনার VPS-এ OCR সার্ভার ──► ফলাফল ফেরত
```

### একটা গুরুত্বপূর্ণ পরিবর্তন: অফলাইন বনাম Base44

Base44 শুধু ওয়েব অ্যাপ বানায়। আমাদের C++ ইঞ্জিন সেখানে সরাসরি চলে না। তাই Base44 পথে:

- অ্যাপ চালাতে **ইন্টারনেট লাগবে**।
- কাগজ যাবে **আপনার নিজের VPS-এ**, অন্য কোনো কোম্পানির AI-তে নয়। গোপনীয়তা আপনার হাতে থাকে।
- নির্ভুলতা হুবহু একই থাকবে। VPS-এ যে ইঞ্জিন চলে, নিচের সব পরীক্ষা সেই ইঞ্জিনেই হয়েছে।
- সম্পূর্ণ অফলাইন ফোন অ্যাপ বাদ পড়ছে না, শুধু পরের ধাপে সরে যাচ্ছে। ইঞ্জিনটা ফোনে চালানোর মতো করেই
  লেখা।

### যেখানে এখনো দুর্বল

- **UP কপি (CamScanner)**: ছবির রেজুলেশন কম, বাংলা অঙ্ক খুব ছোট। ৩০০ DPI বা তার বেশিতে স্ক্যান করলে
  ভালো হবে।
- **UD**: কপি এখনো পাইনি। Scribd লিংক এখান থেকে খোলা যায় না।
- দাগ ছাড়া টেবিল লাইন ধরে লেখা হিসেবে আসে, ঘর ধরে নয়।
- হাতের লেখা পড়ে না।
- বাংলা বানান-সংশোধন নেই।
- টেবিলের "মোট" ঘরের মতো বড়/মোটা অক্ষরের সংখ্যা মাঝে মাঝে ভুল পড়ে। এজন্যই অ্যাপে কম-নিশ্চয়তার ঘর
  হাইলাইট করতে বলা হয়েছে।

## Import Permit-এ ইঞ্জিন নিজে কী যাচাই করে

- Permit No = "ID" + ১০ অঙ্ক, আর প্রথম ৬ অঙ্ক = Permit-এর তারিখ (দিন-মাস-বছর)। বারকোডের নিচের নম্বরের
  সাথেও মেলায়।
- Invoice Value = পণ্যগুলোর FOB-এর যোগফল।
- পণ্যগুলোর Net Weight-এর যোগফল = Total Net Weight।
- Invoice, Undertaking ও LC-র তারিখ Permit-এর তারিখের পরে হলে সতর্ক করে।

যোগফল দিয়ে **একটাই** সম্ভাব্য সংশোধন প্রমাণ হলে (যেমন 6 ↔ 8), ইঞ্জিন ঠিক করে দেয় এবং কী পড়েছিল তা লিখে
রাখে। একাধিক সম্ভাবনা থাকলে কিছু বদলায় না, শুধু "যাচাই প্রয়োজন" দেখায়। আন্দাজে কোনো সংখ্যা বসায় না।

## ধাপে ধাপে যা করবেন

### ধাপ ১: ঠিকানা (HTTPS) ঠিক করা

Base44 ইন্টারনেট দিয়ে আপনার সার্ভারে কাগজ পাঠাবে, তাই সংযোগ এনক্রিপ্টেড (HTTPS) হতে হবে। এর জন্য
সার্ভারের একটা ঠিকানা লাগবে:

- **ডোমেইন থাকলে**: DNS-এ `ocr.example.com`-এর মতো একটা সাব-ডোমেইনের A রেকর্ড দিন, যা VPS-এর IP
  দেখায়। (`example.com`-এর জায়গায় আপনার ডোমেইন।)
- **ডোমেইন না থাকলে**: IP-এর ডটগুলো ড্যাশ করে `.sslip.io` জুড়ে দিন। যেমন IP `203.0.113.5` হলে
  ঠিকানা হবে `203-0-113-5.sslip.io`। এর জন্য কিছু কিনতে বা সেট করতে হয় না।

Hostinger প্যানেলের ফায়ারওয়ালে পোর্ট **80 ও 443** খোলা রাখুন।

### ধাপ ২: VPS-এ OCR সার্ভার চালু করা (একবারই)

Hostinger প্যানেল থেকে VPS-এর IP আর root পাসওয়ার্ড নিন। তারপর কম্পিউটারের টার্মিনাল থেকে:

```bash
# ১. এই প্যাকেজটা VPS-এ পাঠান (নিজের কম্পিউটার থেকে)
scp PersonalScanner_Handoff.zip root@<VPS-IP>:

# ২. VPS-এ ঢুকুন
ssh root@<VPS-IP>

# ৩. Docker আর unzip বসান (একবারই)
curl -fsSL https://get.docker.com | sh
apt-get install -y unzip

# ৪. প্যাকেজ খুলে চাবি ও ঠিকানা লিখুন (ঠিকানাটা ধাপ ১ থেকে)
unzip PersonalScanner_Handoff.zip
cd PersonalScanner_Handoff/personal_scanner/server
echo "PS_API_KEY=$(openssl rand -hex 32)" > .env
echo "PS_DOMAIN=203-0-113-5.sslip.io" >> .env
cat .env            # চাবিটা লিখে রাখুন; Base44-এ লাগবে

# ৫. চালু করুন (প্রথমবার ৫–১০ মিনিট লাগবে)
docker compose up -d --build

# ৬. পরীক্ষা
curl http://127.0.0.1:8080/health     # {"ok":true,...} এলে ইঞ্জিন চালু
```

এরপর নিজের ফোনের ব্রাউজারে `https://<আপনার ঠিকানা>/health` খুলুন। `{"ok":true}` দেখালে HTTPS-ও ঠিক
আছে। সার্টিফিকেট সার্ভার নিজেই আনে ও নবায়ন করে। VPS রিস্টার্ট হলে সার্ভারও নিজে চালু হয়।

### ধাপ ৩: Base44-কে দেওয়া

1. Base44-এ নতুন অ্যাপ খুলুন, নাম দিন **Personal Scanner**।
2. অ্যাপের Settings → Secrets-এ দুটো secret বসান:
   - `PS_API_URL` = `https://<আপনার ঠিকানা>` (যেমন `https://203-0-113-5.sslip.io`)
   - `PS_API_KEY` = ধাপ ২-এ পাওয়া চাবি
3. প্যাকেজের **`1_BASE44_PROMPT.txt`**-এর পুরো লেখা কপি করে Base44 এজেন্টের চ্যাটে পেস্ট করুন। এতেই সব
   নির্দেশনা আছে: কী বানাতে হবে, API কীভাবে ডাকতে হবে, কোন নিয়ম ভাঙা যাবে না।
4. এজেন্ট কাজ শেষ করলে `2_BASE44_BRIEF.md`-এর শেষে **Acceptance checks** অংশটা ধরে মিলিয়ে দেখুন।

Base44-কে C++ কোড বা zip দেওয়ার দরকার নেই। ওরা শুধু নির্দেশনা দেখে অ্যাপ বানাবে। কোডটা থাকবে আপনার VPS-এ।

### Base44-কে যে নিয়মগুলো কড়াভাবে বলা আছে

- সংখ্যা ও লেখা আসবে **শুধু OCR সার্ভার থেকে**। Base44-এর AI দিয়ে কাগজ পড়া বা সংখ্যা "ঠিক করা" নিষেধ।
- OCR-এর মূল মান আর আপনার সংশোধন আলাদা রাখা হবে, কে কখন বদলেছে সহ। অডিটের প্রমাণ হিসেবে কাজে
  লাগবে।
- লাল "যাচাই প্রয়োজন" থাকা অবস্থায় Permit-কে "verified" করা যাবে না।
- কাগজ প্রাইভেট থাকবে। এক ব্যবহারকারী আরেকজনেরটা দেখতে পাবে না।
