# বাংলা অনুবাদক (Bangla Translator)

ইংরেজি ও রুশ ভাষা থেকে বাংলায় **অফলাইন** অনুবাদের মোবাইল অ্যাপ (Android ও iPhone)। অনুবাদের ফল **SutonnyMJ (বিজয়, ANSI)** ফন্টে দেখায়, আর "বিজয় কপি" চাপলে ঠিক সেই ANSI লেখা কপি হয় যা Word-এ SutonnyMJ ফন্টে বসালে হুবহু সুতন্বীএমজে-র মতো দেখায়।

## যা যা আছে

- **অনুবাদ**: English → বাংলা, Русский → বাংলা। Google ML Kit-এর অন-ডিভাইস মডেল ব্যবহার হয়, তাই প্যাক একবার নামানোর পর ইন্টারনেট লাগে না।
- **ফন্ট রূপান্তর**: যেকোনো ইউনিকোড বাংলা লেখা SutonnyMJ (বিজয়) লেখায় রূপান্তর।
- **দুই রকম কপি**: "বিজয় কপি (SutonnyMJ)" — Word/Excel-এ SutonnyMJ ফন্টের জন্য; "ইউনিকোড কপি" — ফেসবুক, মেসেঞ্জার, ইমেইলের জন্য।
- বিজয় টাইপিস্টরা যেভাবে লেখেন সেভাবেই রূপান্তর: শব্দের শুরুতে `†`/`ˆ`, রেফ (`©`), র-ফলার রকমভেদ (`Ö`/`ª`/`«`), উ-কার/ঋ-কারের বিকল্প আকার (`z`, `‚`, `„`), যুক্তবর্ণের আলাদা গ্লিফ (`¶`, `Á`, `š¿`, `¯Í` …)।
- ইংরেজি শব্দ ও SutonnyMJ-তে নেই এমন চিহ্ন (যেমন `৳`) সাধারণ ফন্টে থাকে, যাতে ভুল অক্ষর না দেখায়।

## ইনস্টল

### Android

1. GitHub-এ এই রিপোজিটরির **Actions → Bangla Translator app** খুলুন, সর্বশেষ সফল রান থেকে `bangla-translator-android` ডাউনলোড করুন।
2. zip খুলে `bangla-translator.apk` ফোনে নিন এবং ইনস্টল করুন ("অজানা উৎস থেকে ইনস্টল" অনুমতি দিতে হতে পারে)।

### iPhone

Apple-এর নিয়মে সাইন করা ছাড়া iPhone-এ অ্যাপ বসানো যায় না। দুইটি উপায়:

- **Sideloadly / AltStore** (বিনামূল্যে Apple ID দিয়ে): Actions থেকে `bangla-translator-ios-unsigned` ডাউনলোড করে `bangla-translator-unsigned.ipa` সাইডলোড করুন। ফ্রি Apple ID-তে প্রতি ৭ দিনে আবার সাইন করতে হয়।
- **Mac + Xcode**: `flutter build ipa` চালিয়ে নিজের Apple Developer অ্যাকাউন্ট দিয়ে সাইন করুন (TestFlight/App Store-এর জন্য বছরে ৯৯ ডলারের অ্যাকাউন্ট লাগে)।

## প্রথমবার চালু করার পর

1. **প্যাক ও ফন্ট** ট্যাবে গিয়ে "সব প্যাক নামাও" চাপুন (বাংলা, ইংরেজি, রুশ — প্রতিটি প্রায় ৩০ MB)। এটুকুই একবার ইন্টারনেট লাগে।
2. **SutonnyMJ ফন্ট যোগ করুন**: SutonnyMJ লাইসেন্সকৃত ফন্ট, তাই অ্যাপের সাথে দেওয়া হয়নি। কম্পিউটারের `C:\Windows\Fonts` থেকে `SutonnyMJ.ttf` ফোনে এনে "SutonnyMJ.ttf যোগ করুন" চাপুন।
   - চাইলে বিল্ড করার আগে `assets/fonts/SutonnyMJ.ttf` এ ফাইলটি রেখে অ্যাপের ভেতরেই ফন্ট দিয়ে দিতে পারেন।
3. এরপর থেকে বিমান-মোডেও অনুবাদ চলবে।

## Word-এ ব্যবহার

"বিজয় কপি (SutonnyMJ)" চেপে Word-এ পেস্ট করুন, তারপর লেখাটি সিলেক্ট করে ফন্ট **SutonnyMJ** দিন। অনুবাদে কোনো ইংরেজি শব্দ থাকলে সেগুলোর ফন্ট আলাদা করে Times New Roman করে দিন — বিজয়ে যেমন করা হয়।

## সীমাবদ্ধতা

- অনুবাদ যন্ত্রের করা (Google ML Kit), তাই আইনি বা দাপ্তরিক লেখায় একবার পড়ে নেওয়া দরকার।
- রুশ → বাংলা অনুবাদ ML Kit ভেতরে ইংরেজির মাধ্যমে করে, তাই মান ইংরেজি → বাংলার চেয়ে একটু কম হতে পারে।

## ডেভেলপারদের জন্য

```sh
flutter pub get
flutter analyze
flutter test            # বিজয় রূপান্তরের ৬০টির বেশি টেস্ট সহ
flutter build apk --release
flutter build ios --release --no-codesign
```

- `lib/bijoy/` — ইউনিকোড → বিজয় (SutonnyMJ) রূপান্তরক ও গ্লিফ টেবিল।
- `lib/services/translation_service.dart` — ML Kit অন-ডিভাইস অনুবাদ ও প্যাক ব্যবস্থাপনা।
- `lib/services/sutonny_font.dart` — রানটাইমে SutonnyMJ ফন্ট লোড।
- `tool/convert.dart` — কমান্ড লাইনে শব্দ রূপান্তর: `dart run tool/convert.dart < words.txt`।
- iOS-এ ML Kit-এর জন্য ন্যূনতম iOS 15.5 (`ios/Podfile`)।
